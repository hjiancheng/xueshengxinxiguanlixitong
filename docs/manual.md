# 使用手册（给不懂技术的老师看）

## 一、第一次启动

1. 确认电脑装了 Node.js（版本 22.5 以上）。在命令行输入 `node -v`，能看到 `v22.x` 或更高即可。
2. 把项目文件夹放到任意位置，打开命令行，进入这个文件夹：

```bash
cd "你的项目路径\学生信息管理系统"
```

3. 第一次运行先装依赖（只做一次）：

```bash
npm install
```

4. 启动：

```bash
npm start
```

看到 `学生信息管理系统已启动` 后，打开浏览器访问 <http://localhost:3000>。

> 命令行窗口不能关：关掉窗口服务就停了。要停止服务，在窗口里按 `Ctrl + C`。

## 二、登录

| 账号 | 密码 | 身份 |
| --- | --- | --- |
| admin | 123456 | 管理员（能看全校） |

## 三、日常操作

### 1. 看整体情况（仪表盘）

登录后默认进入仪表盘，四张卡分别是学生总数、班级数、平均分、及格率。下面两张图分别是各班级人数和成绩分段分布，最下面是最近的操作记录。

### 2. 查学生

点左侧「学生管理」：

- **搜索**：在搜索框输入姓名或学号的一部分，点「查询」。
- **按班级/状态筛选**：用两个下拉框，选完点「查询」。
- **翻页**：底部有页码，每页 10 条。
- **看详情**：点某一行的「查看」，弹窗里是这个学生的完整信息和成绩单。

### 3. 新增 / 修改 / 删除学生

- 新增：点右上角「+ 新增学生」，学号、姓名、性别、班级、入学年份必填，学号不能和已有学生重复。
- 修改：点行内「编辑」，改完点「保存」。
- 删除：点行内「删除」并确认。删除后列表里不再显示，但数据仍保存在数据库里（方便以后查档）。

### 4. 导出名单

点「导出 CSV」，浏览器会下载一个 `学生名单-日期.csv`。用 Excel 或 WPS 双击打开，中文不会乱码。导出的是当前筛选条件下的学生。

### 5. 录成绩

点左侧「成绩管理」：

- 先用班级、课程、学期筛选，看要录哪个范围。
- 点「+ 录入成绩」，选班级 → 选学生 → 选课程 → 选学期 → 选考试类型 → 填分数（0~100）。
- 同一个学生、同一门课、同一学期、同一考试类型只能录一次；录错了点「改分」。
- 上方四张卡和分数段图会跟着筛选条件变化。

### 6. 维护班级、课程

- 「班级管理」可以新增班级、改班级名称、指定班主任。**指定班主任后，该教师登录就自动只能看到这个班**。
- 「课程管理」维护课程编码、名称、学分。已经有成绩的课程不能删。

### 7. 查谁改了什么

「操作日志」只有管理员能看，记录了登录、新增、修改、删除、导出，包括时间、操作人、对象、改动内容和 IP。

### 8. 教师账号的差别

用 `teacher` 登录后：只能看到计算机 1 班的 20 名学生和本班成绩，看不到操作日志，也不能改课程和班级。这是「数据范围」在起作用，不是页面坏了。

## 四、常见问题

**Q：端口被占用，启动报 `EADDRINUSE`**
A：说明 3000 端口被别的程序占了。先关掉之前启动的窗口，或者设置端口后再启动：

```bash
set PORT=3001 && npm start
```

（PowerShell 用 `$env:PORT=3001; npm start`）

**Q：想恢复成最初的演示数据**
A：停掉服务，删掉数据库文件再重新生成：

```bash
rm -f school.db school.db-wal school.db-shm
npm run seed
npm start
```

**Q：忘记密码了**
A：演示项目没有找回密码功能。用管理员账号在数据库里改，或者删库重新生成（会清空所有数据）。

**Q：页面打不开 / 一直转圈**
A：先看命令行窗口有没有报错；再访问 <http://localhost:3000/api/health>，返回 `{"code":0,...}` 说明服务是好的，问题在浏览器缓存，按 `Ctrl + F5` 强制刷新。

**Q：能不能给别的电脑用**
A：现在只监听本机。小范围内网演示可以在 `server/index.js` 里把 `app.listen(PORT)` 改成 `app.listen(PORT, '0.0.0.0')`，然后用本机 IP 访问。正式用要换成 MySQL + HTTPS，见 README 的「已知限制」。
